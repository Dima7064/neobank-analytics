# Концепция продукта «NeoBank»

## 1. Что такое NeoBank

**NeoBank** — цифровой необанк без физических отделений. Всё взаимодействие с клиентом — через мобильное приложение и веб-кабинет. Регистрация, верификация, открытие счёта, выпуск карты, переводы, кредиты — онлайн, за минуты.

**Ключевые принципы:**

- **Нет отделений** — низкие издержки, быстрый онбординг.
- **Фокус на UX** — приложение как продукт, а не «канал обслуживания».
- **Прозрачность** — понятные условия, без скрытых комиссий.
- **Скорость** — регистрация за 5 минут, карта — за 1 день.

**Позиционирование:** «Банк, который живёт в твоём телефоне. Без очередей, без бумажек, без скрытых комиссий.»

## 2. Продукты

### 2.1. Дебетовая карта (флагман)

- **Что:** карта с бесплатным обслуживанием, кэшбэком до 5% в выбранных категориях.
- **Монетизация:** интерчейндж (комиссия с каждой покупки, ~1.5%).
- **Кому:** масс-маркет, все новые клиенты.
- **Ключевая метрика:** активация (первая транзакция) в течение 14 дней.

### 2.2. Счёт (базовый продукт)

- **Что:** текущий счёт для переводов, оплаты, хранения денег.
- **Монетизация:** бесплатно (базовый), плюс комиссия с переводов юрлицам.
- **Кому:** все, открывается при регистрации.
- **Ключевая метрика:** частота транзакций.

### 2.3. Вклад (сберегательный)

- **Что:** срочный вклад под 12–16% годовых (в симуляции).
- **Монетизация:** банк использует деньги для кредитования — спред.
- **Кому:** клиенты со свободными деньгами, старше 25.
- **Ключевая метрика:** доля клиентов с вкладом (cross-sell rate), средняя сумма.

### 2.4. Кредитная карта

- **Что:** кредитка с льготным периодом 120 дней, лимит до 300 000 руб.
- **Монетизация:** проценты (если льготный период нарушен), комиссия за снятие.
- **Кому:** клиенты с положительной историей (3+ месяцев активного использования).
- **Ключевая метрика:** approval rate, доля активных кредиток, PD (probability of default).

### 2.5. Потребкредит

- **Что:** кредит наличными до 1 млн руб., ставка 15–25%.
- **Монетизация:** проценты.
- **Кому:** клиенты с историей, проверенная платёжеспособность.
- **Ключевая метрика:** конверсия заявки в выдачу, доля просрочек.

## 3. Целевая аудитория

### Сегмент 1: «Молодые» (18–25 лет)

- **Доля:** ~30% клиентов.
- **Поведение:** мало денег, но активные транзакции (кафе, транспорт, подписки).
- **Ценность:** будущие «взрослые» клиенты,低 LTV сейчас, но высокий потенциал.
- **Метрики:** высокая частота мелких транзакций, средний retention.

### Сегмент 2: «Семьи» (26–45 лет)

- **Доля:** ~50% клиентов.
- **Поведение:** крупные покупки (продукты, ЖКХ, одежда), ипотека, кредиты.
- **Ценность:** ядро бизнеса, максимальный LTV.
- **Метрики:** высокий AOV, cross-sell (вклады, кредиты), лучший retention.

### Сегмент 3: «Премиум» (46+ / высокий доход)

- **Доля:** ~20% клиентов.
- **Поведение:** крупные остатки, инвестиции, премиум-карты.
- **Ценность:** максимальный ARPU, но требовательны.
- **Метрики:** высокий ARPU, низкий churn, высокий NPS.

## 4. Монетизация

| Продукт         | Источник дохода                          | Доля в выручке (план) |
| --------------- | ---------------------------------------- | --------------------- |
| Дебетовая карта | Интерчейндж (~1.5% с транзакции)         | 40%                   |
| Счёт            | Комиссии с переводов юрлицам             | 5%                    |
| Вклад           | Спред (кредитование под более высокий %) | 15%                   |
| Кредитная карта | Проценты, комиссии                       | 25%                   |
| Потребкредит    | Проценты                                 | 15%                   |

**Ключевой принцип:** один продукт не окупает клиента. **Cross-sell — ядро бизнеса.** Клиент с одним продуктом даёт LTV ~10 000 руб., с тремя — ~50 000 руб.

## 5. Конкуренты (для контекста)

- **Т-Банк** — крупнейший необанк РФ, лидер по UX.
- **Ozon Bank** — необанк при маркетплейсе, сильная интеграция с e-commerce.
- **Сбер** — классический банк с digital-каналом, огромная база.
- **Альфа-Банк** — сильный digital, но есть отделения.

**Наше позиционирование:** нишевый необанк для молодой аудитории с фокусом на прозрачность и скорость.

## 6. Ключевые метрики (высокоуровнево)

**Acquisition:** CAC, конверсия из установки в регистрацию.
**Activation:** activation rate (первая транзакция), time to activation.
**Retention:** D1, D7, D30, M1, M3, churn.
**Revenue:** ARPU, LTV, cross-sell rate.
**Risk:** fraud rate, PD (probability of default).

Детальные определения — в `docs/05_metrics_definitions.md`.

## 7. Что НЕ входит в проект

- **Инвестиции** (брокерский счёт) — не симулируем (сложно, отдельная регуляторика).
- **Страхование** — не симулируем (другой домен).
- **Ипотека** — не симулируем (длинный цикл, сложно).
- **B2B-продукты** — не симулируем (фокус на B2C).

**Причина:** фокус на B2C-необанке с 5 продуктами — достаточно для полного цикла аналитики. Остальное — усложнит без пользы для обучения.
