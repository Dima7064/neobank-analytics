# 📓 Дневник аналитика NeoBank

Здесь я записываю ключевые технические и бизнес-проблемы, с которыми столкнулся при разработке симулятора, и как я их решил.

## Этап 1: Инфраструктура и ETL

- **Проблема:** Ошибка `UnicodeDecodeError` при подключении Python к Postgres.
  - _Решение:_ Оказалось, что на Windows локальный Postgres (не Docker) занимал порт 5432. Я перевел Docker-контейнер на порт 5433 и добавил `?client_encoding=utf8` в строку подключения SQLAlchemy.
- **Проблема:** Airflow падал при копировании таблицы `dim_products` с ошибкой `Invalid None value in non-Nullable column`.
  - _Решение:_ В ClickHouse колонки по умолчанию не принимают NULL. Я изменил DDL при создании таблиц в ETL-скрипте, указав тип `Nullable(String)` для всех колонок raw-слоя.

## Этап 2: dbt и данные

- **Проблема:** Мошенники (is_fraud) не находились в данных (все нули).
  - _Решение:_ При генерации булевы значения записались как строки `'true'` и `'false'`. В dbt я использовал функцию `lower(toString(is_fraud)) IN ('true', '1')`, чтобы корректно распарсить флаг мошенничества.

## Этап 3: Machine Learning

- **Проблема:** Модель Fraud Detection выдавала ошибку `IndexError: index 1 is out of bounds`.
  - _Решение:_ В трейне не было ни одного мошенника (класс 1). Я применил `SMOTE` из `imbalanced-learn`, чтобы искусственно создать примеры мошеннических транзакций для обучения модели.
- **Проблема:** `ModuleNotFoundError: sklearn` и ошибка компиляции при `pip install scikit-learn==1.3.2`.
  - _Решение:_ У меня установлен Python 3.13, для которого нет готовых wheel-файлов старых версий sklearn. Я обновил библиотеку до `scikit-learn>=1.6.0`.

## Этап 4: BI и визуализация

- **Проблема:** Metabase не подключался к ClickHouse.
  - _Решение:_ Конфликт версий драйвера и самого Metabase. Было принято бизнес-решение отказаться от Metabase в пользу Power BI и Superset, чтобы не тратить ресурсы на нестабильную инфраструктуру.
- **Проблема:** Power BI не видел таблицы `dm_marts`.
  - _Решение:_ В ClickHouse нет схем, есть только базы данных. При подключении через коннектор ClickHouse нужно оставлять поле "Database" пустым, тогда видны все созданные базы (neobank, neobank_staging, neobank_marts).
