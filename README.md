# NeoBank Analytics

Симулятор аналитики необанка «NeoBank» — полный цикл: от генерации данных до дашбордов и ML.

## О проекте

Это портфолио-проект, который симулирует 12 месяцев жизни необанка. Внутри — весь аналитический путь: генерация реалистичных данных, ETL в Airflow, DWH на Postgres + ClickHouse, витрины через dbt, аналитика в SQL и Python, A/B-тесты, ML-модели (churn, fraud, LTV), дашборды в Power BI / Superset / Metabase, отчёты в Excel и Google Sheets.

## Стек

- **Языки:** Python, SQL
- **БД:** PostgreSQL (OLTP), ClickHouse (OLAP), Greenplum (код)
- **ETL:** Apache Airflow, dbt Core, PySpark
- **BI:** Power BI, Apache Superset, Metabase
- **ML:** scikit-learn, imbalanced-learn
- **Отчёты:** Excel + Power Query, Google Sheets
- **Инфраструктура:** Docker, Git, GitHub Actions
